# Тестовое Neowise. AI-помощник для входящих заявок

Менеджер вводит текст заявки и получает тему и черновик ответа. Он читает результат и сам решает, что отправить клиенту.

## Запуск

Нужен Node.js 20 или новее. Зависимостей и ключей нет.

```sh
node server.mjs
```

Откройте http://127.0.0.1:3000. Порт можно задать через переменную `PORT`:

```sh
PORT=4000 node server.mjs
```

## Тесты

```sh
npm test
```

Без npm тест запускается напрямую:

```sh
node --test test/*.test.mjs
```

Тест поднимает сервер на свободном порту и проверяет успешный разбор, темы `delivery` / `pricing` / `other`, пустой и битый ввод, все сценарии сбоя имитатора (`[error]`, `[bad-json]`, `[bad-topic]`, `[empty-draft]`), таймаут `[timeout]` в пределах 300 мс и отдачу страницы.

## API

`POST /api/triage` принимает JSON:

```json
{ "text": "Когда доставите заказ?" }
```

Ответы:

- `400 {"status":"invalid_input"}` — пустой, отсутствующий или нестроковый `text`, а также битый JSON.
- `200 {"status":"ready","topic":"delivery","draft":"…"}` — модель вернула допустимую тему (`delivery`, `pricing`, `other`) и непустой черновик.
- `200 {"status":"manual_review","topic":null,"draft":null}` — таймаут 300 мс, ошибка модели или неподходящий ответ модели.

На странице при успехе показываются тема и черновик. При `manual_review` показывается сообщение о необходимости ручного разбора, а предыдущий черновик очищается. Ошибка сети и битый ответ сервера также переводят интерфейс в ручной режим.

Имитатор AI не изменялся. Для локальной проверки он принимает любой обычный текст, а метки `[timeout]`, `[error]`, `[bad-json]`, `[bad-topic]`, `[empty-draft]` включают сценарии сбоя.

### Ручная проверка через curl

```sh
curl -s -X POST http://127.0.0.1:3000/api/triage \
  -H 'Content-Type: application/json' \
  -d '{"text":"Когда доставите заказ?"}'

curl -s -X POST http://127.0.0.1:3000/api/triage \
  -H 'Content-Type: application/json' \
  -d '{"text":"[timeout] заявка"}'

curl -s -X POST http://127.0.0.1:3000/api/triage \
  -H 'Content-Type: application/json' \
  -d '{"text":"[error] заявка"}'

curl -s -X POST http://127.0.0.1:3000/api/triage \
  -H 'Content-Type: application/json' \
  -d '{"text":"   "}'
```

## Польза для менеджера

Менеджер быстрее отвечает клиенту за счёт готовой темы и черновика, а при сбое AI не получает пустой или недостоверный ответ и сразу переходит к ручному разбору. Измерять можно медианное время до первого ответа клиенту и долю заявок, отправленных без ручной правки.

## Использование AI

При доработке использовался AI-ассистент. Итоговое поведение проверено локально запуском сервера, curl-сценариями и `npm test`.
